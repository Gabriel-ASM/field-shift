How to read the evidence labels

Every number carries one of these labels, so nobody mistakes an assumption for a measurement.

  • observed counted or measured directly for this place.
  • derived computed from data about this place through a stated method.
  • pooled borrowed from a wider region because local data is thin.
  • prior an assumption, used until data replaces it.
