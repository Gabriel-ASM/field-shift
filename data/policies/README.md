# Políticas de manejo

Não há políticas carregadas neste checkout. Cada política deve ser um JSON conforme `../contracts/strategy-policy.schema.json`, com ação por estado, períodos elegíveis e uma proveniência legível. Vincule as janelas ao ZARC da safra e às restrições agronômicas da cultura/localidade.

O CLI roda a distribuição de estados para a política informada. Sem um modelo econômico explícito, não calcula VPL nem recomenda uma rotação.
