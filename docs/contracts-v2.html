Field Shift Contracts v2

How the v2 schemas connect, what each value of a simulation trajectory holds, and which of those values the current app already reads. Use it to decide what to request from the data team and which soil or climate fields the model actually needs.

Contract map

Monte Carlo runs trajectories over the Markov chain. Every trajectory carries one node (soil, climate, finances). States and transitions change the node only through effects, and effects find their variable by a JSON Pointer such as /soil/pH. Tap a box to highlight its connections.

How a trajectory node behaves

    What a trajectory carries

    Every value an effect can target or a condition can read. The status column says where the value comes from today and whether anything in field_shift/ reads it.

    Carried over from the current model

    Inputs the current model (v1 profiles + field_shift/) depends on, and the v2 field that now holds each one.

    Contracts

    Fields of each schema with their type, unit and bounds, followed by every connection in and out.
